# Sales Performance Dashboard

Excel KPI dashboard built for the Arrowstack Data Analytics internship (Project 1), using simulated 2025 sales data.

**Business question:** Which regions and products should we focus on next quarter?

## Files
- sales_dashboard.xlsx: the dashboard (filters, charts, executive summary, validation)
- project1_final.zip: full project (data, scripts, docs)

## Key results
- Revenue $607,403 | 2,626 orders | AOV $231.30 | Conversion 3.38%
- Laptop Pro 15 is 37.5% of revenue
- November visits rose 67% but orders only 38%, so conversion fell to 2.97%

Data is simulated.
